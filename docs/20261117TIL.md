    1> 깃과 깃허브 

    깃은 소스코드나 파일의 변경이력을 저장하는 프로그램 과거 기록도 한번에 볼수 있다  
    깃허브는 공유하는 서버 

    2> 깃을 올리는 과정 
    깃 허브에서 새 파일을 만들고 
    visual studio나 code 에서 작업한 파일을 
    .git 폴더에 넣고 summary 이름을 작성하고 커밋을 한다 


    3> 로컬과 리모트의 차이점 / 파일의 흐름 이해했는가 로컬했을때 어떻게 되는가 클론했을때 어떻게 되는가

    리모트는 깃 허브 서버에 있는 파일을 가져오는것
