# 게임 루프 
 - 게임 루프란?
 메모장 같은 일반 프로그램은 이벤트 구동방식 
 키를 누르거나 클릭할떄 까지 잠들어 있다가 이벤트가 오면 일함

 게임 루프는 입력이 있든없든 
 스스로 계쏙 도는 반복문 
 이것이 게임 루프 이다 


## 무엇을  
    - 게임 루프를 입력, 갱신 ,렌더링을 프레임(한 바퀴)로 표현한것 

    3요소를 구성
     
     입력 input 이벤트로 만들어줘 
     갱신 update delta time 으로 만들어줘 
     렌더 Render 화면에 그려줘 


    제한없이 while (true)fh ehfflaus 
    컴퓨터가 낼수있는 최대 속도로 돈다 
    60Hz 모니터는 1초에 60장만 보여준다 

    delta time 
    dt 시간을 측정한다 
    시간이 측정된 시점에 1프레임만 그린다 


## 무슨 문제가 발생했나요 ? 

    - 
    -입력이 없으면 영상과 다를게 없다 
    -갱신이 없으면 세계가 멈춘다 
    -렌더링을 멈추면 그림이 멈춘다 (코드 안에서는 움직인다)

    -입력을 길게 누르면 1초간 멈추고 움직인다 
    -업그레이드에 맥스가 있음 3발 이상 업그레이드가 안됨
    -기획 단계에서 레벨 설정이 없음 
    -몬스터가 내려오는게 끝이고 점점 어려워진다거다 그런게 없음 
    -콘솔 특성상 가로와 세로의 크기가 다름
